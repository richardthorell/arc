# ARC Starter Content

The Blank 3D template keeps scene-specific starter assets in the project rather
than exposing them as global Engine built-ins.

## Models

- `models/UAL2_Standard.glb` is the project-local standard reference model used
  for starter/default-scene workflows.

Engine/editor implementation resources remain under the repository-level
`assets/` tree and are not copied into new projects unless the template
explicitly owns them.
